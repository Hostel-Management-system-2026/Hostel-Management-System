# Sprint 1 demo recording script (60 seconds)

Record against a clean local/test environment with demonstration accounts and non-sensitive sample data. Keep the terminal and credentials off screen.

| Time | Demonstration |
| --- | --- |
| 0:00–0:05 | Show the project title and identify Sprint 1 scope. |
| 0:05–0:15 | Sign in as an admin; create a student profile and show that a student can read their own profile. |
| 0:15–0:25 | Allocate a room; show that a second active allocation for the same student is rejected and room capacity is enforced. |
| 0:25–0:35 | Sign in as a student; submit a complaint and show its initial Open status. |
| 0:35–0:45 | Sign in as a warden; move the complaint to In Progress, then Resolved; show that skipping a state is rejected. |
| 0:45–0:55 | Briefly show visitor logging, weekly menu viewing, leave decision, and student notices. |
| 0:55–1:00 | Show the CI test result and state any SDS deviations, including the profile route contract. |

This is a recording plan, not a substitute for the actual video. Add the completed video or a stable share link to the project before submission.
