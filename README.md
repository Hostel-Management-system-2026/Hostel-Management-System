# Hostel Management System

Django REST API and React + TypeScript frontend for hostel workflows.

## Run the frontend

Start the backend from `backend/` with `python manage.py runserver`, then open `frontend/` and run:

```powershell
npm install
npm run dev
```

See [frontend/README.md](frontend/README.md) for the API contract and feature handoff notes.
